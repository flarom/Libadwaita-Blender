# Libadwaita theme for Blender

Implements a GNOME Libadwaita inspired theme for Blender.

![thumbnail](thumbnail.png)

## Installation
1. Download the latest version of the theme from the [releases page](https://github.com/flarom/Libadwaita-Blender/releases).
2. Open Blender and go to `Edit > Preferences > Themes`.
3. Click on the `Install` button and select the downloaded `.xml` file.
